# 🛒 E-Commerce Website using Django & PostgreSQL

A modern and responsive **E-Commerce Website** developed using **Django** and **PostgreSQL**. The system provides customers with a seamless online shopping experience and offers administrators a powerful dashboard to manage products, categories, users, orders, reviews, and contact messages.

# ⚙ Installation

## Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

## Go to Project

```bash
cd YOUR_REPOSITORY
```

## Create Virtual Environment

```bash
python -m venv venv
```

### Windows

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

---

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Configure PostgreSQL

Create a PostgreSQL database and update your `settings.py` with your database credentials.

---

## Run Migrations

```bash
python manage.py makemigrations
python manage.py migrate
```

---

## Create Admin Account

```bash
python manage.py createsuperuser
```

---

## Run the Server

```bash
python manage.py runserver
```

Open:

```
http://127.0.0.1:8000/
```
